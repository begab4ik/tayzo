# Как достать все токены для Tayzo

Все секреты вписываются в файл **`tokens.env`** (он уже лежит в папке, пустой).
Обычные настройки — в `.env`. Оба файла в `.gitignore`, никуда не уйдут.

После заполнения запусти проверку — она скажет, что не так:
```
python -m scripts.check_setup
```

---

## 1. Telegram: BOT_TOKEN, ADMIN_IDS, канал

**BOT_TOKEN**
1. Открой @BotFather → `/newbot` → имя `Tayzo` → username, например `tayzo_bot`
2. Получишь строку вида `7123456789:AAH4k...` — это `BOT_TOKEN`
3. Там же: `/setcommands` не нужен (бот сам выставит), но полезно `/setdescription` и аватарку

**ADMIN_IDS**
1. Открой @userinfobot → он пришлёт твой `Id` (число вроде `123456789`)
2. Впиши. Несколько админов — через запятую: `123456789,987654321`

**REQUIRED_CHANNEL_ID + REQUIRED_CHANNEL_URL** (обязательная подписка)
1. Создай канал проекта (например `@tayzo_news`)
2. Добавь своего бота в **администраторы канала** (права можно минимальные — без этого бот не сможет проверять подписку)
3. ID канала: перешли любой пост из канала боту @userinfobot — он покажет `Id` вида `-1001234567890`
4. `REQUIRED_CHANNEL_URL=https://t.me/tayzo_news`

Потом каналы можно добавлять/убирать прямо из админки бота (📢 Каналы).

## 2. Click Business: SERVICE_ID, MERCHANT_ID, MERCHANT_USER_ID, SECRET_KEY

Нужен **мерчант-аккаунт** (юрлицо/ИП), который у тебя уже есть.

1. Зайди в кабинет **merchant.click.uz** (Click Business)
2. Раздел **Сервисы / Услуги** → твой сервис (или «Создать сервис»):
   - **Service ID** → `CLICK_SERVICE_ID`
   - **Merchant ID** → `CLICK_MERCHANT_ID`
   - **Merchant User ID** → `CLICK_MERCHANT_USER_ID`
   - **Secret Key** (кнопка «Показать/сгенерировать») → `CLICK_SECRET_KEY`
3. В настройках сервиса укажи тип интеграции **SHOP API** и два URL (одинаковые):
   - **Prepare URL**: `https://ТВОЙ-ДОМЕН/webhooks/click`
   - **Complete URL**: `https://ТВОЙ-ДОМЕН/webhooks/click`
4. Домен должен быть **HTTPS** и доступен из интернета. Пока бот крутится на локалке —
   поставь **ngrok** (`ngrok http 8080`) и укажи его адрес; для прода — VPS + Caddy.
5. В `.env`: `WEBHOOK_HOST=https://ТВОЙ-ДОМЕН`

Если названия пунктов в кабинете отличаются — ищи по словам «Service ID», «Secret key», «Prepare/Complete URL»;
если не находится — пиши в поддержку Click, они включают SHOP API и выдают параметры.

Проверка: `curl https://ТВОЙ-ДОМЕН/health` → `{"ok":true}`, затем пополни баланс в боте на 1000 сум.

## 3. Tonkeeper: TON_MNEMONIC, TON_WALLET_VERSION

⚠️ Сид-фраза = полный доступ к деньгам. Держи на этом кошельке только оборотные средства.
Лучше завести **отдельный кошелёк только для бота**, а не личный.

**TON_MNEMONIC**
1. Tonkeeper → ⚙️ **Настройки** → **Резервная копия** (Backup / Recovery phrase)
2. Введи код/биометрию → покажет **24 слова**
3. Впиши их в `tokens.env` через пробел, в одну строку:
   `TON_MNEMONIC=apple banana cherry ... (24 слова)`

**TON_WALLET_VERSION**
1. Tonkeeper → Настройки → **Кошелёк** (или нажми на адрес вверху) → там написана версия
2. **W5** → `TON_WALLET_VERSION=v5r1` (все новые кошельки Tonkeeper)
   **v4R2** → `TON_WALLET_VERSION=v4r2` (старые кошельки, MyTonWallet)
3. Запусти `python -m scripts.check_setup` — он покажет адрес. **Адрес должен совпасть с Tonkeeper.**
   Не совпал → поменяй версию на другую.

**TONCENTER_API_KEY** (необязательно, но лучше сделать)
1. Telegram → @tonapibot → `/start` → `Get API key` → **Mainnet**
2. Ключ → `TONCENTER_API_KEY`. Без ключа лимит 1 запрос/сек — для старта хватит.

Держи на кошельке минимум **0.3 TON сверх** суммы покупок — на комиссии сети.

## 4. Fragment: cookies STEL_SSID, STEL_TOKEN, STEL_DT, STEL_TON_TOKEN

Это самое важное для автооплаты. Fragment не выдаёт API-ключи — бот работает под твоей сессией в браузере.

**Подготовка (один раз)**
1. Открой **fragment.com** в Chrome на компьютере
2. Справа вверху **Log in** → войти через Telegram (подтвердить в приложении)
3. Вверху **Connect TON** → выбери **Tonkeeper** → подтверди в Tonkeeper.
   Должен быть подключён **тот же кошелёк**, сид которого ты вписал выше.
4. Зайди на `fragment.com/stars/buy` и убедись, что можешь нажать Buy (не покупай) — значит аккаунт готов.
   Если Fragment просит **верификацию (KYC)** — пройди, иначе покупки блокируются.

**Достать cookies**
1. На fragment.com нажми **F12** → вкладка **Application** (Приложение)
2. Слева **Storage → Cookies → https://fragment.com**
3. В таблице найди 4 строки и скопируй столбец **Value** каждой:

   | Cookie | Куда |
   |---|---|
   | `stel_ssid` | `FRAGMENT_STEL_SSID` |
   | `stel_token` | `FRAGMENT_STEL_TOKEN` |
   | `stel_dt` | `FRAGMENT_STEL_DT` |
   | `stel_ton_token` | `FRAGMENT_STEL_TON_TOKEN` |

   `stel_ton_token` появляется только после подключения кошелька. Нет его — вернись к шагу 3.
4. `FRAGMENT_API_HASH` можно не заполнять — бот достанет сам. Если хочешь: F12 → **Network** → нажми
   что-нибудь на сайте → запрос `api?hash=XXXX` → XXXX и есть хэш.

**Важно про cookies**
- Они живут, пока ты **не выйдешь** из Fragment в этом браузере. Не нажимай Log out.
- Иногда протухают сами (недели/месяцы). Бот тогда напишет тебе «обнови cookies» и переведёт
  заказы в ручную очередь — ничего не потеряется, просто повтори шаг «Достать cookies» и перезапусти бота.

## 5. Проверить и сделать первую тестовую покупку

```
python -m scripts.check_setup
```
Все четыре блока с ✅ → в конце напишет **«Автооплата через Fragment: ГОТОВА»**.

Тестовая покупка **50 звёзд** на свой аккаунт (спишет ~0.3 TON реально):
```
python -m scripts.check_setup --buy 50 @твой_username
```
Если звёзды пришли — всё, автооплата работает, можно запускать бота:
```
docker compose up -d --build
```

## Если что-то не так

| Симптом | Что делать |
|---|---|
| `BOT_TOKEN неверный` | Скопируй заново у @BotFather, без пробелов |
| `бот НЕ админ` в канале | Канал → Администраторы → добавь бота |
| адрес кошелька не совпадает с Tonkeeper | Смени `TON_WALLET_VERSION` v5r1 ↔ v4r2 |
| `не удалось войти на Fragment` | Cookies скопированы не полностью, или ты вышел из Fragment. Перелогинься и скопируй заново |
| `не удалось получить цену звезды` | То же, либо не подключён кошелёк (`stel_ton_token`) |
| Click не зачисляет | Проверь Prepare/Complete URL в кабинете и что `/health` открывается по HTTPS |
| Заказ упал в ручную очередь | Смотри текст ошибки в карточке заказа в админке; чаще всего — мало TON или протухли cookies |
